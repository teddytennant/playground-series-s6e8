That is a two-branch outcome tree.  It is missing the third branch and it is
missing the sign condition on the first.  The full tree for sending a file x
whose public score is not yet known is:

    (i)   x rounds ABOVE the live top tier (>= 0.97119)
              -> x becomes auto-slot 1 ALONE, under every tiebreak rule

              -> x JOINS the four-way tie, changing its composition
    (iii) x rounds BELOW (<= 0.97117)
              -> auto-slot 1 unchanged; auto-slot 2 may change

w45 section 6 considered only the good half of (ii).  In (i) and in the bad half
of (ii) the sign is set by x's CV, and the queue contains files whose CV is
82-96e-6 BELOW the WANTED file.  This is not a re-pricing of the click -- the
click's value is held fixed at w45a's number.  It prices a DIFFERENT and
previously unpriced decision: WHICH ten of the 77 unsent files to send.

The mechanism is not new; it is the w13 audit exposure, and w39 already acted on
one instance of it (it pulled w36_ad199std_logit from a slot because logit
carries a +1121e-6 LB-CV gap against h3's +1025e-6).  What is new is that w39
fixed one file by hand and w45 section 6 then re-stated the general rule in the
unsafe direction.  A future run following "an unused slot is pure waste, send
everything" sends the logit files.
