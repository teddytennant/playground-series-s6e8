THE FILLER RULE — MECHANICAL, AND FIXED HERE BEFORE THE BOARD IS READ
---------------------------------------------------------------------
Let BASE = sorted(set(TIER1 + TIER2 + WANTED + PLAN_0824)) — w63a's own design, unchanged.
Let dcv(k) = (cv[k] - cv[PICK]) / 1e-6, cv recomputed from the OOF vectors as w63a always does.
Let (LO, HI) = w63a_setprice.json["bracket"]["uncond"]["lo_dcv"], ["hi_dcv"]  (READ, never typed).

    FILL   = { k : oof_{k}.npy exists  AND  k scored on the LIVE board  AND  k not in BASE
                   AND  LO < dcv(k) < HI }                                    <- PRIMARY ARM
    FILLA  = { k : oof_{k}.npy exists  AND  k not in BASE  AND  LO < dcv(k) < HI }  <- ROBUSTNESS

FILL is w77a's rule stated mechanically. FILLA drops the scored condition, which is the one
arbitrary ingredient in it: a filler is withheld from the GLS anyway, so whether it happens to
carry a public score is irrelevant to its role as an abscissa on the cost curve. If the bar
depends on that choice, the bar is not identified and this run must refuse.

THE TREATMENT — WITHHELD FROM THE GLS, WHICH IS w77d's OBSERVATION AND NOT A CHANGE TO `fit`
--------------------------------------------------------------------------------------------

are withheld from LB, so they get xh0 = 0 and are priced through the coupling — exactly what
w63a already does with an unsent plan candidate. No line of `fit` changes.
w78 measured the offset between the two treatments at 0.153e-6 against a 5.56e-6 effect.
