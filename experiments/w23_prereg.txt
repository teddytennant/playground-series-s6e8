1. THE INSTRUMENT — `w23a_bagasym.py`
--------------------------------------------------------------------------------
One honest holdout, never fitted on:

    H  = 20% stratified holdout, seed fixed per replicate
    P  = the remaining 80% = 553,095 rows  <-- EXACTLY the fold-fit n of the
                                                shipped pipeline, by construction

Every number below is `roc_auc_score(y[H], decision_function(Z[H]))`. No
cross-fitting, no OOF re-use, no member selection. Members: the 187-member pack
(`data/ext_members3` on top of ext_members{,2}), HONEST_DROP applied, `hybrid`
transform only (one transform; the asymmetry is a property of each individual stack
fit, and h3/ens4 are rank-averages of such fits).

PART A — the learning surface in (K, n).
    K in {24, 47, 94, 187}   nested member subsets, fixed seed, wider superset of
                             narrower, so dK is not confounded with which members
    n in {0.5, 0.625, 0.8, 1.0} x |P|  = 276k / 345k / 442k / 553k, nested in n
    => 16 fits per replicate, R = 3 replicates (different H and different subsets)

    The quantity of interest is the LAST STEP,
        D_K = AUC(K, n=|P|) - AUC(K, n=0.8|P|),
    which is a 1.25x increase in fit rows -- the same ratio as the shipped
    pipeline's 553,095 -> 691,369. Registered in advance as an UPPER bound on the
    real 553k->691k step, because learning curves flatten, so if D_K comes back
    small the conclusion is safe and if it comes back large it is inflated.

PART B — the penalty, on the same holdout, at K = 187, n = |P|.
    lam (L2 penalty PER ROW) in {0, 1e-8, 3e-8, 1e-7, 3e-7, 1e-6, 3e-6, 1e-5},
    each x {unstandardised, standardised}. C = 1/(lam*n) per fit, so the winner
    transfers to the 691k full fit CORRECTLY -- which is defect (a) above being
    fixed rather than restated. lam=0 maps to the shipped C=1.0.
    16 fits per replicate, R = 3.

Total ~96 fits at ~30s = ~50 min plus a ~120s load. Deterministic given seeds.

2. GATE — registered as a CONDITION ON BELIEVING ANY ROW
--------------------------------------------------------------------------------
Adopting w21b's pattern: re-run an OLD cell inside the NEW harness and let a miss
invalidate the table.

    GATE 1 (Part A): at K=187, n=|P|, lam=0, the holdout AUC must land within
    0.0004 of the shipped cross-fitted 0.970077 for `w20_ad187_hybrid`. A 138k-row
    holdout has an AUC se of roughly 2e-4, and the two numbers are different
    estimands (single 553k fit scored on 138k held-out rows vs a 5-fold mosaic
    scored on all 691k), so this is a sanity gate on the loader/transform/row
    order, NOT a precision test. A miss means the member matrix is wrong.

    GATE 2 (Part B): lam = 1e-8 gives C = 1/(1e-8*553095) = 181, i.e. essentially
    no penalty, and must reproduce lam=0 to within 5e-6 on the same rows. A miss
    means the C-per-fit derivation is wrong.

    Both gates must pass or the wave reports "instrument failed" and ships nothing.

--------------------------------------------------------------------------------
3. HYPOTHESES, WITH THE PREDICTION WRITTEN DOWN FIRST
--------------------------------------------------------------------------------
H1 (Part A, direction). D_K > 0 for every K. Trivially expected; it is here so
   that a NEGATIVE D_K is recorded as a surprise rather than smoothed over.

H2 (Part A, THE LOAD-BEARING ONE). D_K is INCREASING in K. Mechanism: a
   variance-limited fit's AUC deficit goes like K/n, so the gain from n -> 1.25n
   goes like 0.2*K/n, i.e. LINEAR in K. Registered point prediction, and I expect
   to be wrong about the level rather than the sign:
       D_24 ~ +3e-6, D_47 ~ +6e-6, D_94 ~ +12e-6, D_187 ~ +25e-6,
       ratio D_187/D_24 registered as > 3.
   FALSIFIED if D_187 is not the largest of the four, or if the four are flat
   within their own se. A flat surface says the 187-member fit is NOT
   variance-limited at 553k rows, which would kill Part B's premise too and would
   be the more interesting outcome.

H3 (Part B). If H2 lands, an L2 penalty must buy something at K=187, and MORE than
   the +5e-6 measured at 149 members on 08-13. Registered: best lam beats lam=0 by
   +4 to +15e-6, consistent in sign across all 3 replicates, with the optimum at
   lam between 1e-7 and 3e-6. FALSIFIED if the sweep is flat or the argmax is
   lam=0.

H4 (Part B, standardisation). Registered as the weakest of the four and I expect a
   NULL: standardising helps only where the penalty bites, so if H3 fails H4 is
   undefined, and if H3 lands standardisation is worth 0 to +5e-6. The 08-13 note
   calls the unstandardised penalty a 230x-uneven prior, so the honest prior is
   "standardised should be no worse". A standardised-WORSE result at every lam
   would be genuinely informative about which members the fit needs to keep large.

5. THE CONSEQUENCE THAT MATTERS EVEN IF EVERYTHING IS NULL
--------------------------------------------------------------------------------
If H2 lands, then the shipped cross-fitted CV number is a DOWNWARD-BIASED estimate
of the file's true test quality, and the bias GROWS WITH STACK WIDTH. That makes
every CV comparison between stacks of DIFFERENT widths biased -- against the wider
one. Two live comparisons are affected and the direction is worth writing down
before the number exists:
    - `w20_ad187_h3` (187) vs `w16i_schemeavg` (159): the bias favours the 187
      file, i.e. its +45.2e-6 CV lead UNDERSTATES its test advantage. Reassuring
      for the pick that was already made.
    - any future narrow-but-clever file vs the 187 pack: CV would flatter the
      narrow one. This is the trap the finding protects against.
If H2 is FALSE, the correct conclusion is that w20 §5's named mechanism does not
exist at this scale and the 2x residual needs a different explanation -- and
w22's "stop spending slots on beta" then applies with more force, not less.
