THE STATISTIC — fixed here
--------------------------
Unchanged from prereg2 and for the same reason (a rank transform destroys the calibration
the test reads):

    z      = (c - mean(c)) / sd(c)
    S(c,F) = sum_k n_k * (mean of z over f_k)^2

New: the reference distribution is EMPIRICAL and WITHIN-COLUMN. For column c,

    S_obs(c)  = S(c, OURS)                       OURS = agent/common.get_folds(y)
    S_perm(c) = { S(c, F_m) : m = 1..M }         F_m = StratifiedKFold(5, shuffle=True,
                                                       random_state = 90000 + m), on y
    p(c)      = (1 + #{ m : S_perm_m(c) >= S_obs(c) }) / (1 + M)

    M = 199.  Minimum attainable p = 1/200 = 0.005.
    DETECTED(c)  <=>  p(c) <= ALPHA,  ALPHA = 0.01.

Within-column permutation is the point: the SAME column supplies its own null, so a
heavy-tailed or lumpy column cannot manufacture a detection — its heavy tail is present under
every F_m too. The 199 seeds are fixed by the formula above and are not to be re-rolled.

THE CONTROLS ARE THE TEST — both GATING, and both measured on the RIGHT population
-----------------------------------------------------------------------------------
POWER (POS): this workspace's own SINGLE models, oof/oof_*.npy, all of them, evaluated with
    c = the column and OURS = get_folds(y). KNOWN MATCHED, and single models, which is the
    population the pack belongs to. Let POWER = fraction DETECTED.
FALSE POSITIVE (NEG): the SAME single models, but with S_obs taken under a HELD-OUT foreign
    partition StratifiedKFold(5, shuffle=True, random_state=1234) — prereg2's NEG seed, which
    is disjoint from the 90001..90199 permutation block by construction — and the permutation
    null built the same way. KNOWN MISMATCHED. Let FPR = fraction DETECTED.

PREDICTIONS
-----------
G1 GATING (VALIDITY). FPR <= 0.10. The nominal rate is ALPHA = 0.01; allow slack for a
   20-column sample (one detection out of 20 is already 0.05). If FPR > 0.10 the permutation
   null is not calibrated on real columns and the instrument is VOID.
   FAIL => VOID. Report no verdict. Do NOT retune ALPHA, M, or the seed block.
G2 GATING (POWER). POWER >= 0.50 on our own known-matched singles. This is the gate prereg2
   lacked. If fewer than half of KNOWN-MATCHED single models are detected, the test cannot
   establish matching for single models and any count on the pack is uninterpretable.
   FAIL => VOID. ⚠ Note this is a REAL possibility: w80d shows several of our own singles
   sitting at S ~ 0.5-2, indistinguishable from null. VOID on G2 is an honest outcome and
   must be reported as one, not worked around.
G3 THE READ, three-way, no discretion. Let D = #DETECTED among the 50 pack columns and let
   FPR be as measured in G1. Under "the pack is foreign", D ~ Binomial(50, FPR). Let
   p_agg = P(Binomial(50, max(FPR, ALPHA)) >= D).
     p_agg <= 0.001  and  D >= 5   -> MATCHED-EVIDENCE. More columns carry our fold signature
                                      than a foreign pack could produce.
     p_agg >= 0.05                 -> NO-EVIDENCE. The pack shows no more signature than
                                      chance. ⛔ This is NOT proof of foreignness — see (b)
                                      above; the test is one-sided by construction.
     otherwise                     -> INDETERMINATE.
G4 RECORDED, not gating. The per-column detection list, and whether it is a subset of the 11
   columns w80c classed OURS. Recorded to let a successor see whether the two instruments
   agree; it decides nothing.
G5 GATING. Nothing on the send path is touched. md5 of experiments/w79a_barfill.json,
   experiments/w63a_setprice.json, experiments/w26d_queueprice.csv byte-identical.
